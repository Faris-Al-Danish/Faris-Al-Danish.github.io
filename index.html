06 / Featured project

SHALFA — Unmanned Surface Vehicle Prototype

Embedded systems · Computer vision · Autonomous control

Safe mission simulation, no real weapons or hazardous materials

SHALFA is an intelligent Unmanned Surface Vehicle (USV) prototype, built by transforming a conventional RC marine platform into an integrated, multi-functional system that combines embedded systems, computer vision, sensing, autonomous control, and communication technologies.

SensingCamera · MLX90640 thermal · GPS
Raspberry Pi 4Python · YOLOv5 vision
ControlManual / autonomous · Smart Escape
Web interfaceLive camera · thermal · GPS · status

Vision

YOLOv5 computer vision for real-time target detection and tracking.

Sensing & Monitoring

MLX90640 thermal sensor for thermal monitoring and GPS positioning for location awareness.

Control

Manual and autonomous operation with differential motor control, plus a Smart Escape mechanism that automatically recovers when forward movement is obstructed.

Web Interface

A custom web interface with live camera feeds, thermal visualization, GPS information, and system status.

Safe Mission Simulation

LED indicators and audio effects let operational scenarios be demonstrated without real weapons or hazardous materials.

Core Platform

A Raspberry Pi 4 is the main processing and control unit, with the software written primarily in Python.

The software architecture integrates sensing, vision, communication, and control into a single operational platform. The prototype was physically assembled and functionally tested, showing how software and embedded intelligence can turn a conventional RC vessel into a capable experimental unmanned marine platform. SHALFA represents the journey from concept to a real engineering prototype: designed, developed, integrated, and tested as a foundation for future unmanned marine systems.
